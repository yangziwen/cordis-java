Cordis-Java

从 0 构建一个 Agent，从一次模型调用讲到服务化

开始阅读

讲原理，不贴实现

每一章只讲一个方面：要解决的问题、原理、最小验证、以及这个设计放弃了什么。读完你能在白纸上画出自己的 agent 骨架。

完整的骨架标本

文件系统、SQLite、HTTP/SSE、Skill、无头浏览器、模型工具调用循环，以及可直接启动的 AgentServer，依赖方向永远向下。

循环 + 工具 + 历史 + 权限

agent = 一个 for 循环 + 一份工具清单 + 一段可增长的历史 + 一圈默认关死的权限。这四件事分别落在 AgentService、ToolService、MemoryService 与各安全关口上。
